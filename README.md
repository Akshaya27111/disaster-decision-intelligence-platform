# Disaster Decision Intelligence Platform

## Project Overview

The Disaster Decision Intelligence Platform is an enterprise-scale data engineering and AI project designed to support disaster preparedness, emergency response, and recovery.

The platform integrates multiple public data sources, processes them through ETL pipelines, stores them in a PostgreSQL database and data warehouse, performs analytics and machine learning, and provides AI-assisted decision support through dashboards and APIs.

---

## Objectives

- Integrate multi-source disaster data
- Build ETL pipelines
- Design a PostgreSQL database
- Create a data warehouse
- Develop Power BI dashboards
- Build machine learning models
- Develop REST APIs using FastAPI
- Implement AI decision-support agents
